# Backhaul Tunnel Manager

## معرفی

این اسکریپت یک ابزار مدیریتی برای نصب، ساخت و مدیریت تونل‌های Backhaul است.

هدف اصلی پروژه، ساده‌کردن راه‌اندازی و مدیریت تونل بین سرورهای ایران و خارج است؛ به‌خصوص برای شرایط حساس یا سخت شبکه، مانند اختلالات گسترده، محدودیت‌های بین‌المللی و شرایطی مانند اینترنت ملی در ایران.

این ابزار برای استفاده حرفه‌ای روی سرورها طراحی شده و امکاناتی مانند ساخت تونل، مدیریت سرویس، تست اتصال، ویرایش تنظیمات و ری‌استارت خودکار را فراهم می‌کند.

> ⚠️ استفاده از این ابزار باید مطابق قوانین و مقررات محل استفاده انجام شود.

# 🔥 Spoof Tunnel

Spoof Tunnel یکی از قابلیت‌های مهم این پروژه است که برای ایجاد تونل در شرایط سخت شبکه در نظر گرفته شده است.

این حالت برای سناریوهایی مانند:

- اختلال شدید اینترنت
- محدودیت‌های شبکه
- شرایط ناپایدار بین‌المللی
- اینترنت ملی یا شبکه‌های محدودشده در ایران

طراحی شده است.

در این حالت معمولاً یک سرور در ایران و یک سرور در خارج از ایران استفاده می‌شود.

---

## 🇮🇷 سمت ایران

روی سرور ایران، تنظیمات سمت Server ساخته می‌شود.

موارد مهم:

- IP عمومی سرور ایران
- IP عمومی سرور خارج
- IP مربوط به Spoof Source
- IP مربوط به Spoof Destination
- Network Interface
- TUN Address
- Remote TUN Address
- Health Port
- MTU
- PSK

در سمت ایران، PSK به‌صورت خودکار تولید می‌شود.

پس از ساخت کانفیگ، مقدار PSK تولیدشده را برای تنظیم سرور خارج نگه دارید.

---

## 🌍 سمت خارج

روی سرور خارج، تنظیمات سمت Client ساخته می‌شود.

در این قسمت باید PSK تولیدشده در سرور ایران را دقیقاً وارد کنید.

> 🔐 PSK دو طرف باید کاملاً یکسان باشد.

در سمت خارج اسکریپت PSK جدید تولید نمی‌کند و از شما می‌خواهد PSK سرور ایران را وارد کنید.

---

## 🔐 امنیت و PSK

برای ارتباط رمزنگاری‌شده از PSK استفاده می‌شود.

در سمت ایران:

```text
PSK = Automatically Generated
```

در سمت خارج:

```text
PSK = PSK From Iran Server
```

PSK را در اختیار افراد غیرمجاز قرار ندهید.

---

## 🌐 TUN و IPX

Spoof Tunnel از TUN و IPX برای انتقال ترافیک استفاده می‌کند.

مقادیر مهم:

- TUN Name
- Local Address
- Remote Address
- MTU
- Listen IP
- Destination IP
- Spoof Source IP
- Spoof Destination IP
- Network Interface

پروفایل Spoof Tunnel روی ICMP تنظیم می‌شود.

---

## 🔄 Heartbeat

Heartbeat برای بررسی وضعیت ارتباط بین دو سمت تونل استفاده می‌شود.

مقادیر پیش‌فرض:

```text
Heartbeat Interval: 10
Heartbeat Timeout: 25
```

در صورت نیاز می‌توان این مقادیر را متناسب با شرایط شبکه تغییر داد.

---

## ⚡ Performance

اسکریپت تنظیمات مختلفی برای عملکرد تونل در اختیار قرار می‌دهد.

از جمله:

- Workers
- Channel Size
- Socket Send Buffer
- Batch Size
- Tuning Profile
- Auto Tuning

پروفایل پیش‌فرض:

```text
balanced
```

پیشنهاد می‌شود ابتدا با تنظیمات متعادل شروع کنید و سپس بر اساس شرایط سرور و شبکه تنظیمات را تغییر دهید.

# 📡 Port Mapping

در صورت نیاز می‌توان Port Mapping تعریف کرد.

نمونه:

```text

443=5000,80=8080
```

در Spoof Tunnel سمت ایران، Forwarder به‌صورت پیش‌فرض:

```text
iptables
```

استفاده می‌شود.

## 🔁 Auto Restart

برای هر تونل می‌توان ری‌استارت خودکار تنظیم کرد.

برای مثال:

```text
Every 6 hours
```

در صورت فعال بودن Auto Restart، سرویس طبق زمان‌بندی Cron ری‌استارت می‌شود.

---

## 🧪 Connectivity Test

تست اتصال وضعیت کلی تونل را بررسی می‌کند.

موارد قابل بررسی:

- Running بودن سرویس
- وجود TUN Device
- Network Interface
- پاسخ‌گویی Remote TUN Address
- Health Port Configuration
- Default Route

Health Port در این تست به‌عنوان مقدار تنظیم‌شده بررسی می‌شود و صرفاً به معنی وجود یک TCP Listener مستقل نیست.

- Algorithm

# 🧹 حذف

از داخل منوی اسکریپت می‌توان:

- یک تونل خاص را حذف کرد
- سرویس مربوط به تونل را حذف کرد
- Backhaul Core را به‌صورت کامل حذف کرد

قبل از حذف، مطمئن شوید که تونل موردنظر دیگر مورد استفاده نیست.

---

# ⚠️ نکات مهم

1. تنظیمات دو طرف باید با یکدیگر هماهنگ باشند.
2. PSK دو طرف باید یکسان باشد.
3. IPهای TUN باید به‌درستی انتخاب شوند.
4. Interface شبکه باید صحیح باشد.
5. پورت‌های موردنیاز نباید توسط سرویس دیگری اشغال شده باشند.
6. در شرایط سخت شبکه ممکن است نیاز به تغییر MTU یا تنظیمات Tuning باشد.
7. قبل از تغییرات مهم، از کانفیگ پشتیبان تهیه کنید.
8. در صورت استفاده از iptables، قوانین موجود روی سرور را بررسی کنید.
